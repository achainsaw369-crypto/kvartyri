# Мои квартиры

Учёт сдачи квартир в аренду: квартиры, арендаторы, договоры, автоматические начисления, оплаты, залоги, счётчики и поверки, расходы, отчёты и налог. Работает как веб-приложение (GitHub Pages, ставится на iPhone через «На экран Домой») и как APK для Android. Данные синхронизируются между устройствами через ваш приватный репозиторий в зашифрованном виде.

## Что умеет

- **Квартиры** — центральный объект. Стартовый экран — список квартир с жильцом, ближайшим платежом и долгом.
- **Карточка квартиры** с вкладками:
  - **Арендатор**: ФИО, кнопка звонка, задолженность, сколько и когда платить, квадратики оплат по месяцам с января, кнопка «Оплачено» с вводом фактической суммы, изменение суммы платежа с даты (эта дата становится днём ежемесячной оплаты), выселение.
  - **Параметры**: адрес, номер, комнаты, площадь, ставка, ключи, Wi-Fi, лицевые счета, опись имущества.
  - **Счётчики**: следующая и последняя поверка, дата последнего контроля показаний, последнее показание.
  - **Общая информация**: аварийные службы (звонок в одно касание), управляющая компания, код домофона, где краны и щиток. При добавлении квартиры её можно скопировать из другой квартиры того же дома.
  - **Дополнительно**: статистика (получено, расходы, чистыми), оплаты по годам, договоры от новых к старым, расходы.
- **Сводка**: план и факт за месяц и таблица «кто и когда платит» с долгами.
- **Начисления** аренды создаются сами в день платежа, оплаты разносятся по начислениям от старых к новым. Залог учитывается отдельно.
- **Документы**: акт сверки, акт приёма-передачи, расписка с суммой прописью, сообщения по шаблонам.
- **Отчёты**: доходы, расходы, налог (НПД 4/6% или НДФЛ), должники, выгрузка в CSV, календарь .ics.
- **Код-пароль**, тёмная тема, резервная копия, синхронизация между устройствами.

## Установка

### 1. Репозиторий приложения

Создайте **публичный** репозиторий (например, `Kvartiry_android`) и загрузите в него все файлы этой папки с сохранением структуры, включая скрытую папку `.github`. Данных арендаторов здесь нет — только код.

### 2. Веб-версия (iPhone и компьютер)

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту приложение откроется по адресу `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`. На iPhone: Safari → «Поделиться» → «На экран Домой».

### 3. APK для Android

Settings → Secrets and variables → Actions → добавьте три секрета подписи (можно те же значения, что в журнале тренировок):

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD` — только если пароль ключа отличается от пароля хранилища

Сборка запускается сама при изменении `index.html` (или вручную: Actions → «Сборка Android-приложения» → Run workflow). Готовый файл: `https://github.com/ЛОГИН/РЕПОЗИТОРИЙ/releases/latest/download/kvartiry.apk`. Приложение само проверяет новые версии раз в сутки.

### 4. Синхронизация

1. Создайте **приватный** репозиторий для данных, например `kvartiry-data`, с галочкой «Add a README».
2. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token. Repository access: только `kvartiry-data`. Permissions → Contents: **Read and write**.
3. В приложении: «Ещё» → «Синхронизация» → репозиторий, токен и фраза-пароль. На втором устройстве — те же три значения.

Данные шифруются на устройстве (AES-256-GCM, ключ из фразы через PBKDF2) и лежат в репозитории одним файлом `kvartiry.enc.json`. Без фразы его не прочитать. Если фразу забыть, данные из репозитория не восстановить — храните её в менеджере паролей.

Изменения с разных устройств сливаются по записям: побеждает более позднее изменение записи, удаления тоже синхронизируются.

## Новая версия

Поменяйте `const VERSION='…'` в `index.html` и загрузите файл. Веб-версия обновится по кнопке «Обновить» в разделе «Ещё», APK соберётся и появится в Releases.

## Где хранятся данные

На устройстве — в хранилище браузера (или WebView приложения), без шифрования; код-пароль защищает экран. Токен GitHub и фраза хранятся только на устройстве и никуда, кроме api.github.com, не отправляются. Регулярно делайте копию («Ещё» → «Резервная копия»), если синхронизация не включена.
